## Context

当前 IntelliJ SVGA 插件是一个单页面 JCEF 应用，包含：
- 30px 高度的固定顶栏：左侧 7 个背景色切换按钮，右侧文件基本信息（尺寸、版本、FPS、帧数、内存、文件大小）
- 居中 SVGA 动画播放画布（带透明背景棋盘格 SVG）
- 主题系统通过 Kotlin `ThemeJsonBuilder` 将 IDE 的 `JBColor` 推送为 CSS 自定义属性
- 4 个 CSS 自定义属性驱动全部视觉：`--border-color`、`--background-color`、`--font-color`、`--font-family`
- 整体风格为工具性/工业风：极简、功能导向、无装饰性元素

svga.dev 在线播放器的"浏览素材"功能使用 Swiper 翻页实现，包含：
- 左侧：图片预览 + JSON 元数据
- 右侧：可滚动的图片资源列表（key + 尺寸）
- 点击列表项切换预览图

## Goals / Non-Goals

**Goals:**

- 在现有播放页面上新增内嵌 Tab 切换，分为"播放"和"素材"两个视图
- 素材视图展示 SVGA 文件内部图片资源列表，支持点击预览
- 素材视图展示 JSON 元数据（highlight.js 语法高亮）
- Tab 和素材视图完全兼容 IDE 深色/浅色主题切换
- UI 设计与现有播放器风格保持一致（工业风、功能导向）

**Non-Goals:**

- 不引入 Swiper 或其他翻页/滑动库
- 不实现图片导出/下载功能
- 不引入在线素材库浏览能力
- 不实现 SVGA 版本转换功能
- 不做装饰性动画或微交互（保持工具性风格）

## Decisions

### 1. Tab 栏设计：集成到现有顶栏

**决策**: 将 Tab 栏与现有 `#topDiv` 合并，左侧为 Tab 按钮，背景色切换按钮仅出现在"播放"Tab 下。

**理由**:
- 30px 顶栏已有，新增 Tab 不应增加额外垂直空间
- 背景色切换仅与播放画布相关，在素材页显示无意义
- 减少视觉层级，保持工具性极简风格

**布局变化**:
```
现有顶栏:
┌─────────────────────────────────────────────────────────┐
│ [◻][■][□][蓝][绿][黄][红]          750x750 SVGA/2.0 ... │
└─────────────────────────────────────────────────────────┘

新顶栏:
┌─────────────────────────────────────────────────────────┐
│ [播放][素材]  [◻][■][□][蓝][绿][黄][红]  750x750 ...   │  ← 播放Tab激活
│ [播放][素材]  内存占用: 4.4M                    14 图   │  ← 素材Tab激活
└─────────────────────────────────────────────────────────┘
```

**替代方案**: 独立 Tab 栏放在顶栏下方 — 拒绝，因为会占用额外垂直空间，且与现有布局不融合。

### 2. 素材视图布局：左右分栏

**决策**: 左侧 60%（图片预览 + JSON 元数据），右侧 40%（图片资源列表）。

**理由**:
- 与 svga.dev 在线版的比例一致（60%/35%），但右侧加宽到 40% 以适配更窄的 IDE 视口
- 图片预览需要更大空间展示细节
- JSON 元数据放在图片预览下方，形成"视觉信息 → 结构信息"的自然阅读顺序

**布局**:
```
┌───────────────────────────────────────────────────────────────┐
│ [播放][素材]  内存占用: 4.4M                          14 图  │
├──────────────────────────────────┬────────────────────────────┤
│                                  │  ◀ 内存占用: 4.4M ▶       │
│     图片预览区域                  │  ─────────────────────    │
│     (点击列表项切换显示)          │  10 --- 750x673     ◀ ▶  │
│     居中显示，透明棋盘格背景      │  11 --- 750x673          │
│                                  │  01 --- 62x66            │
│                                  │  02 --- 37x62            │
│                                  │  ...                     │
│  ─────────────────────────────  │  xg --- 42x42            │
│  {                              │                           │
│    "version": "2.0",  ← JSON   │                           │
│    "FPS": 15,       元数据       │                           │
│    "frames": 60,     高亮        │                           │
│    "videoSize": {               │                           │
│      "width": 750,              │                           │
│      "height": 750              │                           │
│    }                            │                           │
│  }                              │                           │
├──────────────────────────────────┴────────────────────────────┤
```

**替代方案**: 上下分栏（预览在上，列表在下）— 拒绝，因为 IDE 视口通常宽度充足但高度有限，水平分栏更高效。

### 3. Tab 交互：纯 CSS + JS，无框架依赖

**决策**: Tab 切换通过 CSS class 控制 `display` 属性，JS 仅处理 click 事件和 class 切换。

**理由**:
- 现有代码全部是原生 JS，无框架，保持一致
- Tab 切换是简单状态，不需要状态管理库
- 与 `onSwitchBackground()` 的交互模式一致

**实现要点**:
- 两个容器 `#playerPanel` 和 `#materialPanel`，通过 `.active` class 切换显示
- Tab 按钮通过 `.tab-active` class 标识当前激活状态
- 切换 Tab 时同步更新顶栏中的信息内容

### 4. 图片预览：base64 data URI 渲染

**决策**: 复用 svga.dev 的方式，通过 `background-image: url(data:image/png;base64,...)` 渲染预览图。

**理由**:
- `videoItem.images` 已经是 base64 编码，无需额外转换
- CSP 策略已允许 `img-src data:`，无需修改
- 与在线版实现一致，经过验证

**实现要点**:
- 预览区域使用透明棋盘格背景（复用 `backgroundImage.svg`），与播放画布一致
- 图片居中显示，`object-fit: contain` 语义（通过 `background-size: contain` 实现）
- 点击列表项时更新预览区域背景图

### 5. highlight.js 语法高亮

**决策**: 引入 highlight.js 的核心包 + JSON 语言包，使用 IntelliJ Darcula 风格主题。

**理由**:
- highlight.js 是轻量级语法高亮库，与 JCEF 环境兼容
- 提供 Darcula 主题，与 IntelliJ 深色主题视觉一致
- 支持 `hljs.highlightAuto()` 自动检测，JSON 高亮效果好

**主题适配方案**:
- 深色主题：使用 highlight.js 内置的 Darcula 主题 CSS
- 浅色主题：使用 highlight.js 内置的 GitHub 主题 CSS
- 通过 `onThemeUpdate` 回调动态切换 highlight.js 主题 `<link>` 元素

**资源引入**:
- 文件: `resources/js/highlight.min.js` + `resources/css/hljs-darcula.min.css` + `resources/css/hljs-github.min.css`
- 路由: `SvgaCefRequestHandler` 新增 3 个静态资源映射

**替代方案**: 手写 JSON 着色 — 拒绝，highlight.js 是久经验证的方案，体积可控（核心 ~20KB gzip），效果远优于手写。

### 6. 主题系统扩展

**决策**: 新增 2 个 CSS 自定义属性，并通过 `ThemeJsonBuilder` 推送 IDE 颜色值。

**新增属性**:
- `--tab-active-bg`: Tab 激活态背景色（取自 `JBColor.PanelBackground` 或略深的背景）
- `--hover-bg`: 列表项悬停背景色（取自 `JBColor.PanelBackground` 半透明）

**理由**:
- 现有 4 个属性不足以覆盖 Tab 交互状态
- 从 IDE 取色确保与平台原生 UI 一致
- 不硬编码颜色值，保持主题适配的纯净性

### 7. 顶栏信息动态切换

**决策**: "播放"Tab 下显示原有文件信息（尺寸、版本、FPS 等），"素材"Tab 下显示素材概要（内存占用、图片数量）。

**理由**:
- 顶栏空间有限，两种信息不同时显示
- 素材概要信息在素材视图更相关
- 通过 JS 在 Tab 切换时更新 `#infoDiv` 内容

## Risks / Trade-offs

**[highlight.js 体积]** → 插件包增加约 30-40KB（JS + 2 主题 CSS）。可接受，因为 SVGA 文件本身通常远大于此，且语法高亮对开发体验的提升显著。

**[base64 大图预览性能]** → 某些 SVGA 文件包含高分辨率图片，base64 data URI 渲染可能卡顿。缓解：预览区域限制最大显示尺寸，不渲染原始分辨率。

**[Tab 切换后播放状态]** → 切换到素材 Tab 时播放动画仍在后台运行。这是可接受的行为——切换回播放 Tab 时动画无缝恢复，无需重新加载。不做暂停处理。

**[highlight.js 主题切换]** → 动态切换 `<link>` 元素可能导致短暂闪烁。缓解：在 `<link>` onload 回调中才移除旧主题，或使用 `@import` + CSS class 切换方案。
